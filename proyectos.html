CASO-01 // IDENTIDAD INSTITUCIONAL

Credencial Universitaria — ID UPM

Contexto
La comunidad académica necesita emitir credenciales verificables y administrarlas sin trabajo manual.
Intervención
Implementamos Arch-Credential, el estándar internacional de credenciales, con emisión desde panel y administración de usuarios.
Resultado
En producción: emisión y administración de credenciales operativas para la UPM.
Ver en vivo → Validar credencial → Agendar demo →

CASO-02 // ARMONIZACIÓN CONTABLE

Sistema contable — SCG UPM

Contexto
Una unidad académica con criterios contables que varían entre áreas.
Intervención
Desarrollamos un sistema de armonización contable y gestión académica para la Universidad Politécnica Mesoamericana.
Resultado
En producción, con acceso restringido a personal autorizado.

CASO-03 // IA CONVERSACIONAL
